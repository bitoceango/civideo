# 需求文档：App 三大模块重构（首页 / 分类 / 我的）

> 编号：001 ｜ 状态：草稿（待评审）
> 创建日期：2026-06-13 ｜ 关联：B站 & 爱奇艺/奇巴布 播放器结构调研、`docs/architecture.md`

## 1. 背景与目标
当前 App 只有单一的「视频库」页面，结构单薄。参考主流（B站青少年模式、爱奇艺奇巴布）的成熟信息架构，把 App 重构为 **底部三大模块：首页 / 分类 / 我的**，让内容可发现、可按学科浏览、家长可管控。

**核心目标**：从「一个列表」升级为「有结构的儿童学习型流媒体」，同时严守封闭花园理念（无推荐流、无社交、无电商、无外链）。

## 2. 范围
- **本次要做**：底部 Tab 框架；首页（学科入口+继续观看+收藏+系列聚合）；分类（按学科/能力二级浏览）；我的（家长中心：时长/时段/护眼/学习报告/设备/注销）；视频增加「学科」元数据。
- **本次不做**：离线下载、音频电台、章节书签/课后小测、双语音轨切换、AB 复读、成就徽章（列入后续 Epic，本次不展开）。

## 3. 设计原则 / 约束
- **封闭花园**：无算法推荐流、无榜单/热度、无弹幕/评论/社交、无外链、无电商/会员、无 UGC。
- **儿童友好**：大卡大图少字、固定编排（非无限流）、大按钮、防误触。
- **家庭量级**：不过度设计；分类用「学科/能力」而非分龄（单一年龄段）。
- **家长门**：「我的」整体在家长 PIN 之后。

## 4. Epics 与 Stories

### Epic A：底部 Tab 导航框架
**目标**：把 RootView 从单页改为「首页/分类/我的」三 Tab 容器（iOS 用 TabView，macOS 用 NavigationSplitView 侧栏）。
**范围**：`app/ChildVideo/ChildVideoApp.swift`、新增 `RootTabView`。

- **Story A1 — 三 Tab 外壳**
  - 作为孩子，我想在底部看到「首页/分类/我的」三个入口，以便在不同区域间切换。
  - **AC**：
    - [ ] iOS 显示底部 3 个 Tab（图标+中文标签），macOS 用侧边栏三项。
    - [ ] 激活/休息/播放等全屏态仍能正确覆盖在 Tab 之上。
    - [ ] 切 Tab 不打断正在进行的网络请求；播放页返回回到原 Tab。
  - 改动范围：RootView 重构　｜　依赖：无

### Epic B：首页
**目标**：发现与续学的主入口，固定编排、无推荐流。
**范围**：新增 `HomeView`，复用 `SeriesRow`/`PosterCard`。

- **Story B1 — 学科快捷入口（金刚区）**
  - 作为孩子，我想在首页顶部看到学科图标入口（科学/英语/数理/国学/艺术…），以便一键进入想学的学科。
  - **AC**：[ ] 展示学科宫格（图标+名）；[ ] 点击跳到「分类」对应学科；[ ] 学科集合由内容里实际存在的 category 动态生成。
  - 依赖：Epic E（category 元数据）
- **Story B2 — 继续观看 + 我喜欢的**
  - 作为孩子，我想在首页看到「继续观看」和「我喜欢的」，以便快速接着看。
  - **AC**：[ ] 有进度的视频显示在「继续观看」并带进度条；[ ] 收藏的视频显示在「我喜欢的」；[ ] 均为空时不显示该行。（注：逻辑已存在，迁移到首页）
- **Story B3 — 系列/精选聚合**
  - 作为孩子，我想看到按系列分组的大封面，以便浏览整季内容。
  - **AC**：[ ] 按 series 横向滚动行展示；[ ] 顶部可选 1 个静态「本周精选」位（家长配置，无外链/广告）。

### Epic C：分类（学科 / 能力）
**目标**：按「学科/能力」二级浏览，替代娱乐式频道。
**范围**：新增 `CategoryView`、`CategoryDetailView`。

- **Story C1 — 学科总览**
  - 作为孩子/家长，我想看到所有学科分类，以便选择一个深入。
  - **AC**：[ ] 列出全部 category（来自内容元数据）；[ ] 每个分类显示封面与视频数。
- **Story C2 — 分类详情 + 简单筛选/排序**
  - 作为孩子，我想进入一个学科看到它下面的全部内容，可按系列/时长简单筛选，以便定位。
  - **AC**：[ ] 网格展示该分类视频；[ ] 排序固定为「推荐/进度」，**不暴露热度榜**；[ ] 可按 series 分组。

### Epic D：我的（家长中心）
**目标**：家长 PIN 后的管控与报告中心 + 孩子档案。
**范围**：新增 `MineView`，整合现有 `ParentSettings`。

- **Story D1 — 家长门**
  - 作为家长，我想进入「我的」需要输入 PIN，以便孩子不能乱改设置。
  - **AC**：[ ] 进入「我的」先过 PIN（复用现有 PIN 校验）；[ ] 孩子侧只读档案，管控项在 PIN 后。
- **Story D2 — 时长 / 时段管理**
  - 作为家长，我想设置每日上限和允许时段，以便防沉迷。
  - **AC**：[ ] 复用并迁移现有规则设置（每日上限/允许时段/保存到 Worker）；[ ] 超限/超时段触发休息页（已实现）。
- **Story D3 — 学习报告**
  - 作为家长，我想看到孩子今日/本周观看时长，以便了解情况。
  - **AC**：[ ] 显示今日已看分钟（已存在）；[ ] 增加本周累计（需 Worker 按 day 聚合返回）。
- **Story D4 — 护眼提醒**
  - 作为家长，我想开启「每看 N 分钟提醒休息」，以便保护视力。
  - **AC**：[ ] 可设连续观看提醒间隔；[ ] 到点在播放器弹温和休息提示。
- **Story D5 — 设备与注销**
  - 作为家长，我想查看已激活设备并能注销本机，以便管理。
  - **AC**：[ ] 显示设备名/今日已看（已有）；[ ] 注销清 Keychain 回激活页（已有）。

### Epic E：内容元数据 —「学科」字段（前置依赖）
**目标**：让视频带 `category`（学科），支撑首页金刚区与分类。
**范围**：`cli/`（cpv 增 `--category`）、`worker`（manifest 透传）、孩子端读取。

- **Story E1 — cpv 增加 --category**
  - 作为家长（AI 上传），我想给视频打学科标签，以便分类展示。
  - **AC**：[ ] `cpv upload --category "科学"` 写入 manifest；[ ] 缺省为「未分类」；[ ] `/api/library` 返回 category；[ ] 客户端 Video 模型新增 category 字段。

## 5. 数据 / 接口影响
- **manifest.json / cpv**：视频条目新增 `category` 字段（Epic E）。
- **Worker**：`/api/library` 透传 category；`/api/progress` 可选增「本周累计」聚合（D3）。
- **D1**：无需新表（watch_daily 已可按 day 聚合）。
- **客户端**：`Video` 增 `category?`；`AppModel` 增 `categoryGroups`。

## 6. 里程碑 / 优先级
- **P0（先做，打地基）**：Epic A（Tab 框架）、Epic E（category 元数据）。
- **P1**：Epic B（首页）、Epic C（分类）、Epic D1/D2/D5（家长门+时长+设备，多为迁移现有）。
- **P2**：Epic D3（本周报告）、D4（护眼提醒）。

## 7. 测试与验收总览
- 每个 Story 按其 AC 验收。
- 端到端：上传带 category 的视频 → 首页金刚区出现该学科 → 分类能进入 → 播放 → 我的过 PIN 看到时长。
- 两端构建通过（macOS + iOS 模拟器）；iOS 模拟器 simctl 截图核对三大模块 UI。
